# Design → Bento316 Shopify store

**This repo is not the storefront.** `bento316-shopify` is the Next.js
dashboard app; the live store's theme (Liquid `sections/`, `templates/`,
`assets/`) is the sibling repo **`issawilliams5-ux/bento316-shopify-store`**,
which carries the full version of this skill.

1. If `bento316-shopify-store` is in this session (`/home/user/bento316-shopify-store`),
   read its `.claude/skills/shopify-design-import/SKILL.md` and do the work
   there.
2. If it isn't, attach it with `add_repo` (owner `issawilliams5-ux`, repo
   `bento316-shopify-store`), clone it, then continue as in step 1.
3. Only if the user clearly means *this* Next.js app (a dashboard or
   marketing page, not the store), use the [`clone-website`](../clone-website/SKILL.md)
   skill here instead, following this repo's `app/` and `components/`
   conventions.

Either way, the source must be ours to copy: for a competitor or third-party
site, reproduce the layout pattern only, with Bento316's own copy, images and
branding.
